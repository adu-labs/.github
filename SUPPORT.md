# Support

Adu Labs is currently maintained on a best-effort basis.

- Use an issue for reproducible bugs and scoped feature requests.
- Use repository discussions, when enabled, for design questions and general
  usage help.
- Use private vulnerability reporting for security issues.

Before asking for help:

1. Read the repository README and current limitations.
2. Search existing issues and discussions.
3. Reduce the problem to a minimal reproduction.
4. Remove credentials, personal information, employer data, and private logs.

Commercial support and paid consulting are not currently offered through this
organization profile.
