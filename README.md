# Adu Labs organization files

This repository contains the public profile and default community health files
for the `adu-labs` GitHub organization.

GitHub renders [`profile/README.md`](profile/README.md) on the organization
overview page. The remaining files provide organization-wide defaults for
repositories that do not define their own contribution, support, security, or
issue-reporting policies.

Maintainers complete identity isolation, clean-room review, and organization
hardening through a private pre-publication checklist.
